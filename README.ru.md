# course-maker

*[Read this in English](README.md)*

От самой общей идеи курса — до готовых слайдов лекций, конспекта для
лектора, лабораторных, тестов и домашних заданий — за часы или дни, а не
недели или месяцы. Структурированный AI-пайплайн для подготовки материалов
университетского курса, с отслеживанием состояния, чтобы ничего не терялось
и не приходилось объяснять одно и то же ИИ-помощнику от сессии к сессии.

> Скилл — кросс-инструментальный [Agent Skill](https://agentskills.io)
> (`SKILL.md`), поэтому в теории должен работать в любом инструменте,
> поддерживающем этот стандарт; явно протестирован в **Claude Code** и
> **Cowork**, **OpenAI Codex CLI** и **Cursor** — один скилл, устанавливается
> в каждый инструмент отдельно (см. [Установку](#установка)). Более глубокий
> паритет между инструментами описан в
> [docs/MULTI_HARNESS_PLAN.md](docs/MULTI_HARNESS_PLAN.md) (на английском).

## Зачем

Подготовка курса обычным способом — это недели: план слайдов, который
расходится с тем, что реально рассказываешь на лекции; Beamer-файлы, которые
требуют вёрстки; конспект, написанный по памяти накануне вечером;
лабораторные и система оценивания, которые каждый семестр приходится
настраивать заново. Обычный чат с искусственным интеллектом этого не решает: 
каждая сессия начинается с чистого листа, поэтому информацию о целевой 
аудитории и об ограничениях курса приходится объяснять заново, 
а одни и те же неудачные идеи — отклонять снова и снова.

course-maker — это пайплайн, а не чат: он помнит аудиторию курса, стиль и
все принятые решения, и превращает это в согласованный, готовый к
использованию материал.

- **Скорость:** одна лекция — план, иллюстрации, слайды, конспект — за часы или даже минуты;
  целый новый курс с лекциями, лабораторными и тестами — за несколько дней.
- **Точно под вашу аудиторию:** уровень строгости, язык и стиль задаются один
  раз и применяются к каждой лекции, лабораторной и тесту — без повторных
  объяснений и расхождений.
- **Курс, который переживёт следующий семестр:** любой курс — это
  предсказуемая структура файлов с явной таблицей статусов и журналом
  решений, поэтому обновить одну лекцию или вернуться к курсу спустя год —
  дело минут, а не археологии.

## Что умеет

Один пайплайн — весь курс, а не только слайды:

| Для... | Что получаете |
|---|---|
| **Лекций** | план слайд за слайдом → список визуализаций → Python-скрипт для генерации иллюстраций → генерация слайдов Beamer/Slidev по частям → конспект лектора |
| **Семинаров** | тот же пайплайн лекций плюс практическая часть — Jupyter ноутбук для live-кодинга |
| **Лабораторных** | план → ноутбук → техзадание для преподавателя → автотесты на pytest → проверка «глазами студента» → публикация в вашу LMS |
| **Тестов / экзаменов** | интерактивный план создания оценочных средств → генерация банка вопросов с ключом ответов → подготовка версии для выдачи студентам |
| **Домашних заданий** | бриф задания + критерии оценки → раздаточный материал для студентов (pdf/latex/docx) |
| **Самого курса** | `course_plan.md` как единый источник истины, сгенерированный студенческий силлабус и дашборд статуса по всем пайплайнам |

Для одной лекции это выглядит так:

```
/course-maker plan 3        # подробный план слайд за слайдом
/course-maker visuals 3     # список визуализаций: TikZ или Python
/course-maker figures 3     # Python-скрипт для генерации PNG-иллюстраций
/course-maker slides 3      # презентация LaTeX/Beamer (по частям)
/course-maker slides 3 next # ...следующие 5 слайдов
/course-maker notes 3       # конспект лектора (по частям)
```

Каждый шаг читает результаты предыдущих шагов и `history.md`, в котором
фиксируется каждое решение и отклонённая идея — поэтому ИИ-помощник не
предлагает повторно то, что вы уже отвергли, а каждая следующая лекция учитывает уроки
из предыдущих. У лабораторных, семинаров, тестов и домашних заданий — свои
пайплайны в том же духе, полный список см. в разделе
[Команды](#команды).

## Установка

**Требования:** любой агент, поддерживающий стандарт
[Agent Skill](https://agentskills.io) (протестировано на Claude Code, Cowork,
OpenAI Codex CLI и Cursor), плюс git. Для локальной компиляции Beamer —
дистрибутив LaTeX. Для автоматических тестов в лабораторных работах —
Python 3.11+.

Один и тот же скилл (`SKILL.md` + `references/`) работает в любом
инструменте, различается только способ установки. Выберите один из двух
вариантов.

### Вариант A — релизный zip-архив (любой инструмент; единственный способ для Cowork)

Скачайте `course-maker-vX.Y.Z.zip` из
[последнего релиза](https://github.com/markpolyak/course-maker/releases/latest).
Это самодостаточная версионированная копия скилла — одна папка
`course-maker/` — с зашитой в неё версией.

- **claude.ai / Claude Cowork:** загрузите zip как есть через
  **Settings → Features** (Skills). Не распаковывайте.
- **Claude Code / Codex / Cursor:** распакуйте в папку скиллов нужного
  инструмента. Архив уже содержит папку `course-maker/`, так что она встанет
  на своё место:

  ```bash
  unzip course-maker-v1.3.0.zip -d ~/.claude/skills/   # Claude Code
  unzip course-maker-v1.3.0.zip -d ~/.agents/skills/   # Codex CLI
  unzip course-maker-v1.3.0.zip -d ~/.cursor/skills/   # Cursor (только если не используете вариант выше)
  ```

  Чтобы обновиться — скачайте новый архив и распакуйте заново.

### Вариант B — клон + симлинк (для разработки / отслеживания `main`)

Хороший вариант, если хотите одним `git pull` обновлять скилл сразу во всех
инструментах, или если вы сами дорабатываете скилл. Для Cowork не подходит.
Выполняйте из РОДИТЕЛЬСКОЙ директории клона:

```bash
git clone https://github.com/markpolyak/course-maker

# Claude Code:
ln -s "$(pwd)/course-maker/skill" ~/.claude/skills/course-maker

# Codex CLI:
mkdir -p ~/.agents/skills
ln -s "$(pwd)/course-maker/skill" ~/.agents/skills/course-maker
```

Замените `ln -s` на `cp -r`, если нужна самодостаточная копия (тогда
копировать заново после каждого обновления).

**Cursor отдельной установки не требует** — он тоже читает папки скиллов
Claude Code и Codex, поэтому подхватит любой из симлинков выше. (Используете
только Cursor? Положите симлинк в `~/.cursor/skills/course-maker`.)

Затем создайте курс и инициализируйте его в своём агенте:

```bash
# Создать новый репозиторий курса
mkdir my-course && cd my-course && git init

# Открыть в Claude Code / Codex / Cursor и инициализировать
> /course-maker course init
> /course-maker course plan
```

`course init` создаёт `AGENTS.md` (контекст курса), `course_conventions.md`,
`slides_preamble.tex` и структуру директорий. `course plan` пошагово
помогает заполнить `course_plan.md` (или импортировать уже существующий).

## Быстрый старт (5 минут до первого плана слайдов)

1. Выполните `/course-maker course init` — заполнит `AGENTS.md` (контекст
   курса) и шаблоны курса по вашим ответам (название курса, аудитория, стиль,
   язык, формат слайдов, движок LaTeX).
2. Выполните `/course-maker course plan` — интерактивно создаст
   `course_plan.md`, либо импортирует уже готовый.
3. Выполните `/course-maker plan 1` и просмотрите результат.
4. Когда всё устраивает — выполните `/course-maker visuals 1`.

Полное пошаговое руководство:
[docs/getting-started.md](docs/getting-started.md) (на английском).

## Как это сокращает число итераций

Два основных источника лишних кругов при подготовке лекции:

**Проблема 1: ИИ-помощник не помнит, что вы отклонили.**
Каждая сессия начинается с чистого листа. Вы говорите «сожми раздел 3»,
помощник это делает, а через неделю раздел снова разросся. → Файл `history.md`
для каждой лекции решает это: каждое решение фиксируется и перечитывается в
начале каждого шага.

**Проблема 2: слайды Beamer зависают или переполняются.**
Файл `.tex` на 20 слайдов — это 600–900 строк. Генерация за один проход
рискует подвесить инструмент или оборвать вывод — в любом из поддерживаемых
инструментов. → Слайды и конспект генерируются частями по 5, с
подтверждением после каждой части.

Третий источник — ИИ-помощник незаметно пропускает файл `references/*.md`,
упомянутый в диспетчере команд, — решается блоком `## Inviolable rules` в
`SKILL.md`: он загружается всегда и содержит критические правила, которые
действуют даже при пропуске остального.

## Структура репозитория (на курс)

```
my-course/
  AGENTS.md               ← контекст курса (аудитория, стиль, язык, профиль)
  course_plan.md          ← мастер-план (источник истины)
  syllabus.md             ← студенческий силлабус (генерируется из course_plan.md)
  COURSE_STATE.md         ← статус всех пайплайнов: ✅ 🔄 ❌ ⚠️
  course_conventions.md   ← терминология и языковые правила (создаётся в course init)
  slides_preamble.tex     ← преамбула LaTeX/Beamer (создаётся в course init)
  lab_templates.md        ← шаблоны ноутбука/тестов лабораторной (создаётся в lab course-init)
  lms_adapter.md          ← сценарий публикации в LMS (копируется из профиля в lab course-init)
  lectures/
    01/
      plan.md             ← план слайд за слайдом
      visuals.md          ← список визуализаций с оценкой пригодности TikZ
      figures/
        figures.py        ← генерирует все PNG-иллюстрации
        fig01_name.png
      slides.tex          ← презентация Beamer
      speaker_notes.md    ← текст для лектора, читаемый вслух
      history.md          ← журнал решений
  labs/
    shared/               ← общие для курса базовые шаблоны
    lab1/
      lab_spec.md         ← контракт только для преподавателя (не публикуется студентам)
      history.md
      starter/            ← файлы для студентов (способ доставки зависит от адаптера LMS)
        exercises.ipynb
        conftest.py
        tests.py
        ...
  seminars/               ← колоды семинаров + практические ноутбуки
  quizzes/                ← банки тестов/экзаменов + студенческие версии
  homework/               ← брифы домашних заданий + критерии (или вложены в семинар)
```

## Команды

**Пайплайн лекций:**

| Команда | Описание |
|---|---|
| `/course-maker` | Статус проекта (все пайплайны) |
| `/course-maker help` | Справочник команд |
| `/course-maker course init` | Развернуть новый репозиторий курса |
| `/course-maker course plan` | Создать, заполнить или обновить course_plan.md (интерактивно) |
| `/course-maker course status` | Таблица статусов по всем пайплайнам |
| `/course-maker course update` | Найти ручные правки в course_plan.md, пометить затронутые лекции |
| `/course-maker doctor` | Проверка рассинхронизации состояния, отсутствующих файлов, пробелов в конфиге (только чтение) |
| `/course-maker stats` | Прогресс-бары по всем пайплайнам (только чтение) |
| `/course-maker syllabus [pdf\|latex\|docx]` | Сгенерировать/обновить студенческий syllabus.md; опционально экспортировать |
| `/course-maker plan N` | Шаг 1: подробный план слайдов для лекции N |
| `/course-maker visuals N` | Шаг 2: список визуализаций |
| `/course-maker figures N` | Шаг 3: Python-скрипт генерации иллюстраций |
| `/course-maker slides N` | Шаг 4: слайды Beamer, часть 0 (преамбула + титул) |
| `/course-maker slides N next` | Шаг 4: следующая часть из 5 слайдов |
| `/course-maker notes N` | Шаг 5: конспект лектора, слайды 1–5 |
| `/course-maker notes N next` | Шаг 5: следующая часть из 5 слайдов |
| `/course-maker status N` | Статус + сводка истории для лекции N |

**Пайплайн семинаров** (колода лекции + практическая часть, в seminars/NN/):

| Команда | Описание |
|---|---|
| `/course-maker seminar plan\|visuals\|figures\|slides\|notes N` | Шаги колоды — переиспользуют пайплайн лекций, но для seminars/NN/ |
| `/course-maker seminar practice N` | Практический ноутбук с live-демонстрацией кода (practice.ipynb) |
| `/course-maker seminar status N` | Статус + последние 3 записи истории |

**Пайплайн лабораторных:**

| Команда | Описание |
|---|---|
| `/course-maker lab course-init` | Разовая настройка: создать labs/shared/ с шаблонами; установить адаптер LMS |
| `/course-maker lab init N [url] [slug]` | Развернуть лабораторную N (стартовые файлы по адаптеру LMS; url используется только в профилях с удалённым стартовым репозиторием) |
| `/course-maker lab plan N` | Шаг 1a: интерактивное планирование до утверждения |
| `/course-maker lab notebook N` | Шаг 1b: сгенерировать exercises.ipynb |
| `/course-maker lab spec N` | Шаг 1b: сгенерировать lab_spec.md (авто-режим plan/notebook) |
| `/course-maker lab datasets N` | Шаг 1b: сгенерировать datasets_info.md (опционально) |
| `/course-maker lab tests N` | Шаг 2: tests.py, requirements.txt, README (+ grade_report.py, если используется репортер) |
| `/course-maker lab validate N <id>` | Шаг 3: проверка «глазами студента» (нужна новая сессия) |
| `/course-maker lab publish N` | Запустить сценарий публикации из lms_adapter.md (зависит от LMS) |
| `/course-maker lab update N` | Переопубликовать после исправления после релиза |
| `/course-maker lab status N` | Статус + последние 3 записи истории |

**Пайплайн тестов** (тесты / контрольные / экзамены):

| Команда | Описание |
|---|---|
| `/course-maker quiz plan N` | Шаг 1: интерактивный план теста (блоки, типы вопросов, варианты) |
| `/course-maker quiz generate N [next]` | Шаг 2: сгенерировать банк вопросов (по частям, блок за блоком) |
| `/course-maker quiz publish N [format]` | Шаг 3: экспортировать студенческую версию (markdown) |

**Пайплайн домашних заданий** (задание с ручной проверкой — без автогрейдинга):

| Команда | Описание |
|---|---|
| `/course-maker homework plan N [dir]` | Шаг 1: интерактивный бриф задания + критерии оценки (по умолчанию dir — homework/NN/) |
| `/course-maker homework publish N [format]` | Шаг 2: собрать раздаточный материал для студентов; markdown по умолчанию, pdf/latex/docx через pandoc |
| `/course-maker homework status N` | Статус + последние 3 записи истории |
